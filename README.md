# BlockerOP

An Android app for blocking the usage of certain apps during a defined timeframe, with advanced uninstall protections to prevent bypassing restrictions.

## Features

- Block selected apps during configurable time windows
- Advanced uninstall protection to enforce restrictions
- Clean, customizable UI
